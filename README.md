# QuickQR

A private, polished QR code studio that runs entirely in the browser.

## Features

- Live QR generation for links and text
- Custom foreground and background colors
- High-resolution PNG export
- Clipboard image copy
- Small local-only history
- Responsive, accessible interface

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Privacy

QuickQR has no backend. Content and history stay on the device.
